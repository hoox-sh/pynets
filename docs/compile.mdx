# PyneTS compile

## Abstract

PyneTS compile (`mode: "compile"` / `"auto"`) **emits a JavaScript bar-loop function**. It is the analog of Python **object-mode** compile, **not** Numba nopython. There is no LLVM, no `numba`, no disk IR cache like `PYNE_COMPILE_CACHE_DIR`.

Landed in **0.2.0**. **0.4.0** emitted the later TA, matrix, drawing, strategy, and host names. **0.5.0** added footprint mocks, `plot.style_*`, and `alert.freq_*`. **0.11.x** routes both backends through the shared descriptor tables in `src/runtime/ta_specs.ts`, so the 165 TA methods (11 tables) resolve identically in interpret and compile. Python Runtime remains the oracle.

## Conceptual model

```mermaid
flowchart LR
  AST[ASDL AST] --> ELIG[compileEligible]
  ELIG -->|no| INT[interpret]
  ELIG -->|yes| EMIT[emitScript]
  EMIT --> FN[bar-loop JS function]
  FN --> RUN[compiled.run columns]
  RUN --> RES[RuntimeResult mode compile]
  EMIT -->|error and auto| INT
```

|                                | Python compile                                | PyneTS compile                             |
| ------------------------------ | --------------------------------------------- | ------------------------------------------ |
| Backend                        | Numba nopython **or** object-mode Python loop | **JS emit only**                           |
| Default `Runtime.run`          | `interpret` (env override)                    | `interpret`                                |
| `auto`                         | try compile, fallback interpret               | same                                       |
| `import` / foreign `request.*` | limited; often fallback                       | inline registered libs; foreign → `na`     |
| Alerts / drawings / strategy   | object-mode path                              | `__h.strategy`, drawings, `alertcondition` |

## Interface surface

```ts
import {
  compileScript,
  transpile,
  compileEligible,
  clearCompileCache,
  compileCacheStats,
  runScript,
  CompileError,
} from "@hoox-sh/pyne-ts";

new Runtime("AAPL", { mode: "compile" }).run(src, bars);
new Runtime("AAPL", { mode: "auto" }).run(src, bars);
```

| Name                                                         | Role                         |
| ------------------------------------------------------------ | ---------------------------- |
| `compileEligible(tree)`                                      | `{ ok, reason? }`            |
| `transpile` / `compileScript`                                | Emit + wrap `CompiledScript` |
| `compiled.run(open, high, low, close, volume, time, extras)` | Columnar execute             |
| `clearCompileCache` / `compileCacheStats`                    | Process-local emit cache     |

CLI: `bunx pyne-ts -- run script.pine --mode compile` or `--mode auto`.

### What emit covers

**0.2.0.** Strategy object-mode (`__h.strategy` / fills / events), UDF series state (`src[1]`, `var` locals), array / map / matrix, UDT (`Type.new`, field get-set, `method`), drawings (`label` / `line` / `box`), named UDF kwargs, input overrides, `color.*`, enums, `request.security` same-symbol passthrough (foreign → `na`), `barstate.*` / `syminfo` stubs, calendar, `str.*` / `str.format`, `import` (inline registered sources; unresolved → `na`), `session.*` / `chart.*`, `log.*`, `ticker.new` / `standard` / `heikinashi`, `request.currency_rate`, `alertcondition`.

**0.4.0.** The later interpret names: `ta.uo` / `rci` / `dpo` / `kst` / `stochrsi` / `donchian` / `ichimoku` / `bb_pct` / `emv` / `fractal` / `atr_stop` / `zigzag`, the bar-mode detectors (`hammer`, `gap_detector`, `macd_signal`, `acceleration_factor`, `stoch_smooth`, `engulfing`, `inside_bar_pattern`, `double_top_bottom`, `voi`, `bid_ask_imbalance`, `rsi_oversold_overbought`, `rsi_divergence`, `cumulative_delta`, `volume_momentum`, `volume_profile_high` / `low`, `volume_thrust`), matrix row/col stats, `strategy.cash` free cash and trade-history fields, `timenow`, `max_bars_back`, `plot.linestyle_*`, bare `random`, bare `security_lower_tf`, and drawing getters / `*.all` / `*.copy` / `chart.point.*` / `line.fill`. `array.from` collects its arguments.

**0.5.0.** `request.footprint` mock, `footprint.*` / `volume_row.*` accessors, `request.seed`, `plot.style_*`, `alert.freq_*`.

**0.11.x.** Shared descriptor tables (`src/runtime/ta_specs.ts`): both backends resolve the 165 TA methods through the same specs — argument kinds, tuples, gates, and overloads are no longer maintained twice. Waves 11–14 analytics (`ta.sma_weighted` … `ta.expected_value`, `ta.gamma_levels`, `ta.intelligent_strategy_synthesizer`, `ta.signal_confluence`) emit on both backends, and every wave ships with Python `Runtime.run` parity tests.

`mode: "auto"` no longer skips compile when inputs are set.

### In the browser

Compiled output uses `new Function`. A strict CSP without `script-src 'unsafe-eval'` will block it — use `mode: "interpret"` there, or allow `'unsafe-eval'` on the worker that hosts the evaluation. The `browser` export condition resolves to a `node:`-free bundle; the parser-only subpath `@hoox-sh/pyne-ts/parse` needs no eval at all.

## Internals

| Path                                                 | Role                                |
| ---------------------------------------------------- | ----------------------------------- |
| `src/runtime/compile/engine.ts`                      | `compileScript`, `runScript`, cache |
| `src/runtime/compile/emit.ts`                        | JS text emit                        |
| `src/runtime/compile/emit_call.ts`                   | Builtin / UDF calls                 |
| `src/runtime/compile/emit_udf.ts`                    | User functions                      |
| `src/runtime/compile/runtime.ts`                     | Host helpers used by emitted code   |
| `src/runtime/interpret.ts` `runCompiled` / `runAuto` | `Runtime.run` wiring                |

Do not edit `src/runtime/compile/*` and `src/runtime/interpret.ts` in the same change. Parent wires `Runtime.run({ mode })`.

## Invariants & edge cases

1. **Not Numba.** Do not document `nopython`, `njit`, or `PYNE_COMPILE_CACHE_DIR` for this package.
2. **Python still wins** if compiled plots disagree with Python interpret on the same script+bars — unless Python compile is the thing being compared, in which case compare apples to apples (`object` vs `object`).
3. **`import` / foreign `request.*` stay interpret-or-na.** No invented bars.
4. `result.mode` reports what **ran** (`interpret` or `compile`). After `auto` fallback, read `compile_fallback_reason`.
5. Compile failures in `mode: "compile"` return an error envelope; `auto` falls back.

## Worked examples

```ts
const interpret = new Runtime("AAPL", { mode: "interpret" }).run(src, bars);
const compiled = new Runtime("AAPL", { mode: "compile" }).run(src, bars);
const auto = new Runtime("AAPL", { mode: "auto" }).run(src, bars);

if (compiled.error) {
  // inspect compiled.error / error_kind
}
console.log(auto.mode, auto.auto_backend, auto.compile_fallback_reason);
```

```bash
bunx pyne-ts -- run script.pine --mode auto --json
```

## Failure modes

| Symptom                              | Cause                 | Fix                                               |
| ------------------------------------ | --------------------- | ------------------------------------------------- |
| `CompileIneligibleError` / fallback  | Surface not emitted   | `interpret`, or extend emit (parity first)        |
| Plots differ interpret vs compile    | Emit bug              | Add `test/compile_*.test.ts`; Python is still SoT |
| Expecting Numba speedups             | Wrong mental model    | This is JS object-mode                            |
| Editing compile + interpret together | Review / merge hazard | Split the change                                  |
