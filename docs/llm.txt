PyneTS is the TypeScript / Bun library for Pine Script: parse, unparse,
interpret, JS-compile. Python pynescript is the source of truth; when
semantics disagree, Python wins. Package: @hoox-sh/pyne-ts (current 0.11.1).
Not a Cloudflare Worker, not Numba, not a TradingView product.
