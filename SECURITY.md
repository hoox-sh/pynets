# Security Policy

## Supported versions

Security fixes land on the default branch (`main`). There is no long-term
support branch.

## Reporting a vulnerability

Do **not** open a public GitHub issue for security problems.

Report privately to the maintainer (**jango_blockchained**) via:

- GitHub Security Advisories on this repository (preferred), or
- A private channel linked from the GitHub profile

Include steps to reproduce, impact, and a suggested fix if you have one.

We will acknowledge receipt when possible and coordinate disclosure.

## Scope

This repository is the TypeScript / Bun library `@hoox-sh/pynets` (parse, unparse,
interpret). Sister projects (PYNE / pynescript, edge hosts, charting UI) have
their own policies.
